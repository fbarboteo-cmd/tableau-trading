Connexion au dépôt GitHub

Comment obtenir ce token ?
Sur GitHub : Settings (de votre compte, pas du dépôt) → Developer settings → Fine-grained tokens → Generate new token. Limitez-le à votre dépôt d'alertes uniquement, avec la permission Contents: Read and write. Sans la case « Se souvenir », le token reste en mémoire le temps de la session seulement ; avec la case, il est gardé dans ce navigateur jusqu'à ce que vous appuyiez sur « Oublier ».
